# aalaya.space

A human-to-human emotional support platform. Two people, anonymous, present.
No therapists, no chatbots, no profiles to scroll. AI is safety infrastructure
only — never a companion, never a replacement for human connection.

aalaya is **not** therapy, not crisis support, and not a social network. If you
are in crisis in the UK, contact [Samaritans (116 123)](tel:116123) or text
SHOUT to 85258.

## Status

Early development. The site currently serves a landing page only; auth,
profiles, presence, and chat ship in later phases.
